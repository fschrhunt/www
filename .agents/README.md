# A little taste, on file

This folder helps future work feel considered and personal, with room for pages
that look nothing like the homepage. It does not
supply a personality by installing dependencies. We checked.

Start with [the site brief](site.md). The root `AGENTS.md` points agents to the
relevant skill. Tools that support repo-local skill discovery can discover the
folders under `.agents/skills`; otherwise ask the agent to read the path.

| Task | Skill | Ready-to-use prompt |
| --- | --- | --- |
| Write something worth reading | [www-write](skills/www-write/SKILL.md) | [Write a note](prompts/write-a-note.md) |
| Explore and build a page | [www-design](skills/www-design/SKILL.md) | [Make a page](prompts/make-a-page.md) |
| Improve an existing page | [www-design](skills/www-design/SKILL.md) | [Give it a polish](prompts/polish-a-page.md) |
| Find what still feels wrong | [www-review](skills/www-review/SKILL.md) | [Review a page](prompts/review-a-page.md) |

Paste a prompt into a task and fill its short input section, or refer to its
file and provide the details in your message. Prompts are starting points;
missing optional detail should not stop useful work.

Keep this kit small. When Fischer accepts a new direction, update the relevant
part of the brief. When a real failure repeats, add the smallest useful example
or check. Do not turn every one-off preference into a permanent rule.
