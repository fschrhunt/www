# Model and provider icons

Canonical icon SVGs vendored from `@lobehub/icons-static-svg@1.95.0`
([Lobe Icons](https://github.com/lobehub/lobe-icons)). The package is MIT licensed;
see [LICENSE](LICENSE). Brand names and marks remain their owners’ trademarks.

Includes every canonical icon in that release, excluding separately named text and alternate
color/brand variants. The chart uses CSS masks to display the marks in its current
soft-white color. Icons are loaded individually as needed, with no runtime CDN
requests or npm dependency. `catalog.json` lists the available slugs.

`../provider-icons.js` maps model families to their creators. Hosting tools such
as OpenCode do not determine a model’s icon. Unknown models get a neutral mark.

`xiaomi.svg` is from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/xiaomi.svg), retrieved September 8, 2026, under [CC0](LICENSE-simple-icons.md). MiMo uses this compact creator mark instead of its wordmark.
